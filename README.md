# Medical Insurance Forecast

A DATA 555 project that predicts individual medical charges using `insurance.csv`. The notebook includes data cleaning, exploratory plots, and a comparison of multiple linear regression models with and without a BMI and smoking interaction.

## Quick start

Use Python 3.13 (tested) and VS Code with the Python and Jupyter extensions.

1. From the project folder, run these commands in PowerShell:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. Open `Project_1_Medical_Insurance_Regression.ipynb` in VS Code.
3. Select `.venv` as the notebook kernel, then choose **Run All**.

The written plan and final results are in the [proposal](project%20proposal.pdf) and [report](project%20report.pdf).
