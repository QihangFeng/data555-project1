# Medical Insurance Cost Prediction

## About This Project

This is a DATA 555 course project that analyzes and predicts **individual medical insurance charges** based on personal characteristics like age, BMI, smoking status, and other factors.

### What You'll Learn

- How data cleaning prepares raw information for analysis
- Visual exploration of patterns in medical insurance data
- How statistical models can predict future costs
- Comparing different approaches to find the best prediction method
- The relationship between BMI and smoking status in determining insurance costs

### Who This Is For

- **Students** learning data analysis and statistical modeling
- **Researchers** interested in healthcare cost factors
- **Anyone curious** about what influences medical insurance prices

---

## Getting Started

### Prerequisites

- Python 3.13 (tested version)
- VS Code with the [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python) and [Jupyter](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter) extensions

### Installation & Setup

1. **Open a terminal** in your project folder (or use PowerShell on Windows)

2. **Create and activate a virtual environment:**
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

3. **Open the notebook** in VS Code:
   - Open `Project_1_Medical_Insurance_Regression.ipynb`
   - When prompted, select `.venv` as your Python kernel
   - Click **Run All** to execute the analysis

### Output

The notebook generates:
- Data cleaning results
- Exploratory charts and visualizations
- Model comparisons and predictions
- Final results and insights
